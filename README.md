# Practicando-Python-para-Data-Science-Challenge-
Challenge 01 Python, Data Science 
Este Repositorio contiene el primer Challenge del modulo Data Science
Consiste en que a partir de 4 archivos que contienen la información de 4 tiendas, la que debemos cargar y a partir de ellos
se debe obtener las siguientes estadisticas:

1. Análisis de facturación
2. Ventas por categoría
3. Calificación promedio de la tienda
4. Productos más y menos vendidos
5. Envío promedio por tienda

A partir de los resultados de estas consultas, se debe evaluar que tienda debe cerrar el señor Juan
